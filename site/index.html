A live island in the dead space around your camera.

Isle fills the black band either side of the MacBook notch with what Spotify is playing — album art, a waveform driven by the actual audio signal, and transport controls that unfold when your pointer gets close. It never takes focus, and it folds back out of the way the moment you leave.

The waveform is not a loop. The demo synthesises its audio in your browser, runs an FFT over the live output, and reduces the spectrum to six log-spaced bands, tilted so the high bars stay alive — the same reduction SystemAudioLevels.swift runs on Spotify's captured signal. Hover the island to expand it; drag the playbar to seek.

Fig. 1 — Isle on a 14" display, 1:1 scale

What it does

Six things, each one sized to the space it has.

The notch is roughly 190 points wide and 34 tall. Everything below had to earn its place in that band, or in the panel that unfolds from it.

Collapsed

Now playing at a glance

Album art on the left of the camera, waveform on the right. The cutout itself is the divider — nothing is ever drawn under the lens.

Signal

A waveform from the real audio

A Core Audio process tap on Spotify feeds an FFT. The bars move with your track, not with a timer, and not with anything else playing on the system.

Expanded

Full transport, on hover

Play, pause, next, previous, shuffle, repeat, and a scrubbable playbar. The panel opens under the pointer and closes when you leave.

Artwork

Cover art decoded sharp

A 640 px sleeve drawn into 22 points aliases badly on the default filter. Isle decodes at true pixel resolution, so the thumbnail stays crisp.

Clock

A playbar that doesn't stutter

Position is smoothed against its own anchor and eased toward what Spotify reports, so it stays continuous between coarse updates and through seeks.

Window

Never steals focus

A borderless, non-activating panel with no Dock icon. It is created at full size and only its contents animate, so the window server never has to reflow under your cursor.

The thing that costs everyone a day

Since roughly macOS 15.4, MRMediaRemoteGetNowPlayingInfo returns an empty dictionary to unentitled apps rather than failing. The call succeeds, so an app built the textbook way silently never shows a track and nothing in the logs says why. Verified through macOS 26.5. Reads go through the adapter subprocess; commands, which aren't gated, go straight to Spotify. The two paths stay separate on purpose.

Claude Code

The other thing worth putting up there.

Isle watches a running Claude Code session and shows its state in the same band. When Claude needs your approval, the island opens on its own — you don't have to be looking at the terminal. Pick a state to see it.

Claude's hooks write a small status file per session under ~/.isle/sessions/; Isle watches the directory with file-system events and ranks by urgency, so a background session can't overwrite the one you're watching. Install the hook from the menu bar — it merges into ~/.claude/settings.json without disturbing what's already there.

Install

Two permissions, then it's out of your way.

Isle uses a private framework and AppleScript automation, which rules out the Mac App Store. It ships as a signed disk image you install yourself, and it updates itself from there.

Download and drag to Applications

A 0.1.3 disk image, universal. First launch is right-click → Open, since the build is sideloaded rather than notarised through the Store.

Isle-0.1.3.dmg

Allow it to control Spotify, and to hear it

macOS asks twice: Automation, for the transport controls, and audio capture, for the waveform. Decline the second and everything still works — the waveform falls back to a procedural pattern rather than going dead.

Optional — wire up Claude Code

From the menu bar, Install Claude Code Hook… drops a helper into ~/.isle/bin and merges the hook entries into your settings.

Or build it from source

Xcode 16+. The build script fetches a pinned upstream tag of the adapter, compiles a universal framework, and drops it into place.

# one-time: build the bundled now-playing bridge
./scripts/build-mediaremote-adapter.sh

open Isle.xcodeproj   # then ⌘R
